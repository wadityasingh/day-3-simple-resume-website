# Simple Resume Website

This is my Day 3 internship project at Veda Technology. I created a personal resume website using HTML and CSS.

The website includes my education, skills, projects, internship experience, certifications, and contact details.

## Technologies Used

- HTML
- CSS

## Features

- Simple and clean design
- Works on mobile and desktop
- Separate sections for resume details
- Links to my projects and LinkedIn profile

## Projects Included

- PocketBuddy
- ShoppingIndia
- Personal Portfolio Website
- CampusSync

## Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code to preview the website.
